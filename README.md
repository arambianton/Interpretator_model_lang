# Работа интерпретатора

Интерпретатор реализован как конвейер из четырёх независимых, но связных модулей. Каждый модуль принимает результат предыдущего и передаёт свой вывод дальше.

Вывод результата происходит следующим образом:
Текст → Lexer → Tokens → Parser (+Semantics) → Statements + Poliz → Runtime → Результат.
